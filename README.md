# Grok Bot Virtual Meetup Backgrounds

Create **1920×1080** virtual backgrounds for Zoom and Google Meet with a Grok Bot sticker, background/character colors, and corner placement.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Download options

| File | When to use |
|------|-------------|
| **Download PNG** | Google Meet, and Zoom when you want others to see branding in the chosen corner |
| **Download mirrored PNG** | Zoom self-view if the preview is mirrored — logos/text stay readable to you |

Both exports are the same resolution (`1920×1080`). The mirrored file is a horizontal flip of the standard composition.

## Apply in a call

- **Zoom:** Settings → Background & Effects → Virtual Backgrounds → add image
- **Google Meet:** More options → Apply visual effects → Add image / Upload

Keep branding in a corner so your face stays clear in the center.
